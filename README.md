# Clinicon Frontend

واجهة Clinicon مبنية باستخدام React و Vite، وتحتوي على تجربة Frontend تفاعلية للأدوار التالية:

- المريض
- الطبيب
- مالك العيادة
- معمل التحاليل

## التشغيل من VS Code

1. افتح هذا الفولدر في VS Code.
2. افتح Terminal داخل الفولدر.
3. شغّل:

```bash
pnpm install
pnpm dev
```

4. افتح الرابط الذي يظهر في الـ Terminal.

## ملاحظات

- التطبيق يعمل ببيانات تجريبية محلية حتى يمكن تجربة التنقل والتسجيل والحجز والطابور وباقي الشاشات بدون إعداد Backend.
- ملف اللوجو الأصلي موجود في `attached_assets/image_1787110154301.png` ويتم استخدامه داخل الواجهة.
- لتغيير الهوية البصرية أو الألوان، راجع `src/index.css`.
- نقطة البداية الرئيسية هي `src/App.tsx`.
